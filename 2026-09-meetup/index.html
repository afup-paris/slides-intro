Actu PHP


Versions supportées

PHP 8.6 : où en est-on ?

  • 10 septembre : 8.6.0 beta 3
  • 22 septembre : feature freeze
  • 24 septembre : 8.6.0 RC1
  • 19 novembre : sortie prévue de PHP 8.6

PHP 8.6 : nouveautés côté langage

  • Partial Function Application : des closures avec paramètres pré-remplis
  • Propriétés readonly avec valeur par défaut
  • Commentaires de doc au niveau des paramètres (ReflectionParameter::getDocComment())

PHP 8.6 : nouveautés côté stdlib

  • clamp() pour borner une valeur
  • SortDirection : une enum pour trier
  • Time\Duration : durées avec précision nanoseconde
  • Io\Poll : API de polling native (epoll, WSAPoll)
  • grapheme_strrev() respecte les caractères Unicode

PHP 8.6 : sécurité par défaut

  • session.use_strict_mode = 1
  • session.cookie_httponly = 1
  • session.cookie_samesite = Lax
  • Des réglages sûrs sans rien configurer

PHP 8.6 : exemples

$makeSlug = str_replace(' ', '-', ?);
$makeSlug('Hello World'); // Hello-World

clamp(101, min: 0, max: 100); // 100

$query->orderBy('created_at', SortDirection::Descending);

sleep(Duration::fromMilliseconds(500));

Symfony Polyfill

  • clamp(), SortDirection, grapheme_strrev() : polyfill-php86
  • Io\Poll : polyfill-io-poll (PHP 8.1+)
  • Time\Duration : polyfill-time (PHP 8.1+)
  • Non "polyfillable" : Partial Function Application, readonly avec défaut, réglages de session

Polyfill : installation ciblée

composer require symfony/polyfill-php86
composer require symfony/polyfill-io-poll
composer require symfony/polyfill-time

Objectif : garder le même code, le temps de migrer.
