Actu PHP


Versions supportées

PHP 8.6

  • 13 août : 8.6.0 beta 1
  • 27 août : 8.6.0 beta 2

PHP 8.6 : nouveautés

  • clamp() pour borner une valeur
  • SortDirection : une enum pour trier
  • grapheme_strrev() respecte les caractères Unicode
  • Io\Poll et Time\Duration
  • Meilleurs messages d'erreur pour json_decode()

PHP 8.6 : exemples

$volume = clamp($volume, 0, 100);

    $query->orderBy('created_at', SortDirection::Descending);

echo grapheme_strrev('Développeur PHP');

Symfony Polyfill

  • Des API PHP récentes sur des versions plus anciennes
  • Activé uniquement si l'API native n'existe pas
  • PHP 8.6 : clamp(), SortDirection
  • grapheme_strrev(), Io\Poll, Time\Duration

Polyfill : installation ciblée

composer require symfony/polyfill-php86

# ou les composants dédiés
composer require symfony/polyfill-io-poll
composer require symfony/polyfill-time

Objectif : garder le même code, le temps de migrer.
